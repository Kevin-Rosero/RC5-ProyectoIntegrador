# Sistema de Puntuación para Evaluación de Adoptantes

## Objetivo

El sistema asigna una puntuación automática a cada formulario completado por un solicitante. Cada respuesta tiene un valor determinado según qué tan favorable sea para el bienestar de la mascota.

La puntuación máxima es de **100 puntos**.

# Cálculo de la puntuación

El sistema suma automáticamente los puntos obtenidos en cada pregunta.

**Ejemplo:**

* Vivienda: Casa sin patio → **8 puntos**
* Tiempo sola: Entre 2 y 5 horas → **8 puntos**
* Recursos económicos: Sí, completamente → **15 puntos**

**Total parcial:** 31 puntos.

Las respuestas que no sean las ideales **no descalifican automáticamente** al solicitante; simplemente reciben una menor cantidad de puntos. Esto permite que el sistema evalúe el perfil de manera equilibrada, considerando todos los aspectos del formulario.

---

# Interpretación del resultado

| Puntuación          | Resultado                                                                                                      |
| ------------------- | -------------------------------------------------------------------------------------------------------------- |
| **90 – 100 puntos** | Apto para adopción. El sistema recomienda la aprobación automática.                                            |
| **70 – 89 puntos**  | Apto con revisión. El administrador debe revisar el formulario antes de aprobar la adopción.                   |
| **50 – 69 puntos**  | Requiere entrevista adicional. Existen aspectos que deben aclararse con el solicitante.                        |
| **0 – 49 puntos**   | No apto. El solicitante no cumple con varios criterios importantes para garantizar el bienestar de la mascota. |

---

# Evaluación manual

La pregunta **"¿Por qué desea adoptar una mascota?"** no forma parte del cálculo automático de la puntuación.

Esta respuesta será revisada únicamente por el administrador, quien podrá:

* Validar que las intenciones del solicitante sean responsables.
* Detectar posibles inconsistencias con las respuestas del formulario.
* Aprobar o rechazar la solicitud en casos especiales, incluso si la puntuación automática es alta o baja.

De esta forma, el sistema combina una evaluación objetiva mediante puntuación con una revisión humana cuando sea necesario.
